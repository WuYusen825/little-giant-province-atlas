# 小巨人企业省级分布与增长（2019—2025）

基于用户整理的七批CSV名单，统一为31个省级单位，另分析深圳、宁波、青岛、大连、厦门。

- 年度名单数、同比、全国份额、累计按名称去重数量
- 年份和指标可切换的中国省级地图
- 省级排名、三年窗口份额变化、增长贡献、集中度
- 五个单列城市的数量、增长与本省占比

## 数据口径

共19,442条名单记录，按标准化企业名称跨年去重为19,333个名称。年度名单数保留跨年重复。省级统计已包含单列城市，城市明细不可再与省级总数相加。

2024年宁波独立标签缺失，其单列数量及受影响同比留空。源CSV未见记录的省级零值只描述所给文件，不证明官方数量为零或名单完整。累计不是当前仍有效认定存量。缺少统一社会信用代码，名称去重不等于法人实体精确去重。

## 使用

网页为静态文件，可直接通过GitHub Pages访问。`data/`保存汇总CSV；原始逐企名单、企业审计底表与用户本地路径不发布。`analysis/`为计算脚本，须配合原始CSV在原项目目录结构下运行。`source/`保存本报告的网页内容代码，网页产品运行库已编译在index.html中。

地图边界：[阿里云DataV](https://datav.aliyun.com/portal/school/atlas/area_selector)，仅用于统计展示。
